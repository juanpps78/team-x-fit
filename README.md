# TeamX Fit

PROMPT — TEAM-X | MVP ETAPA 1

Actúa como Product Manager, diseñador UX/UI y desarrollador Full-Stack especializado en aplicaciones fitness.

Quiero crear una primera versión funcional de una aplicación llamada:

TEAM-X

La aplicación está dirigida a personas que entrenan en gimnasios y necesitan tener sus rutinas organizadas y disponibles desde el teléfono.

El problema que queremos resolver es sencillo:

Actualmente muchos gimnasios entregan las rutinas en papel, por WhatsApp o de forma verbal. El usuario termina olvidando qué ejercicio debe hacer, cuántas series, cuántas repeticiones o cuánto peso utilizar.

TEAM-X debe solucionar esto de la manera más simple posible.

IMPORTANTE

Esta es solamente la ETAPA 1 / PRUEBA DEL MVP.

NO quiero que construyas todavía una plataforma completa para gimnasios.

Quiero una primera versión rápida, funcional y visualmente atractiva que permita comprobar la experiencia principal del producto.

Prioriza:

Simplicidad + velocidad + facilidad de uso.

No agregues funciones innecesarias.

1. EXPERIENCIA PRINCIPAL

El flujo principal debe ser:

ABRIR TEAM-X → VER ENTRENAMIENTO DE HOY → EMPEZAR → REGISTRAR EJERCICIOS → TERMINAR → VER PROGRESO

El usuario debe poder entender la aplicación sin recibir instrucciones.

9. COACH IA — SOLO COMO DEMO

Incluir una pequeña sección llamada:

Mostrar preguntas sugeridas:

"¿Qué entreno hoy?"

"¿Cómo puedo sustituir un ejercicio?"

"¿Cuánto descansé en mi último entrenamiento?"

"¿Cómo voy con mi progreso?"

Si la plataforma permite conectar fácilmente un modelo de IA, implementar una versión básica.

Si no lo permite rápidamente, dejar la interfaz preparada para la integración posterior.

NO retrasar el MVP por esto.

14. DISEÑO MOBILE-FIRST

La aplicación debe diseñarse primero para teléfonos.

La pantalla más importante es:

ENTRENAMIENTO DE HOY

Los botones deben ser suficientemente grandes para utilizarse mientras la persona está entrenando.

No obligar al usuario a escribir demasiado.

Siempre que sea posible utilizar:

botones

selectores

valores rápidos

/ -

listas

en lugar de campos de texto largos.

15. EXPERIENCIA DURANTE EL ENTRENAMIENTO

Este punto es especialmente importante.

Cuando la persona está entrenando probablemente tiene:

las manos ocupadas

poca atención disponible

poco tiempo

Por eso cada ejercicio debe ser extremadamente fácil de registrar.

Ejemplo:

REPETICIONES

[-] 10 [+]

GUARDAR

SIGUIENTE EJERCICIO →
